1. 表：US_Semiconductor_Manufacturing_2016_2025.csv

美国半导体制造业的产能、投资、就业与产能利用率年度数据；用于检验制造回流（reshoring）是否发生。

列名称	类型	单位	说明
Year	int	年	数据年份（2016–2025）。
US_Global_Capacity_Share_Percent	float	%	美国在全球半导体晶圆制造产能（WSPM）中的占比。反映在全球制造中的地位。
Industry_CAPEX_BillionUSD	float	十亿美元	美国半导体制造业年度资本支出（建厂、扩产、设备投资）。是“制造回流”的先行指标。
Manufacturing_Employment_Thousands	float	千人	NAICS 334413 半导体制造业就业人数。劳动力回流指标。
Fab_Utilization_Percent	float	%	晶圆厂产能利用率。体现需求周期、高低端节点紧张程度。
📌 2. 表：US_Import_IC_ByCountry_2016_2025.csv

美国集成电路（HS 8542）进口额分来源国年度数据。用于分析贸易转移、脱钩（decoupling）进程。

列名称	类型	单位	说明
Year	int	年	数据年份。
Total_Imports_Bn	float	十亿美元	美国进口 IC（HS8542）总额。
China_Bn	float	十亿美元	来自中国大陆的 IC 进口额。
China_Share_Percent	float	%	中国 IC 进口占美国总 IC 进口的比例。脱钩核心指标。
Malaysia_Bn	float	十亿美元	马来西亚 IC 进口额（主要是封测基地）。
Taiwan_Bn	float	十亿美元	台湾 IC 进口额（主要是先进逻辑芯片与晶圆）。
Vietnam_Bn	float	十亿美元	越南 IC 进口额（封装测试增长快，是中国替代国之一）。
📌 3. 表：US_Tariff_ExportControl_Events_2016_2025.csv

经政策编码的关税/出口管制事件表，可直接用于 DID / 事件研究 / 合成控制。

列名称	类型	单位	说明
Year	int	年	事件发生的年份（如政策跨年，以颁布年份记录）。
Date	string	YYYY-MM-DD	事件发生的精确日期（如官方颁布日）。
Event_Type	string	类别	政策类型，如 Section301、BIS_Oct7、EntityList 等。
Description	string	描述	对政策的简要说明（文本变量，可用于定性分析）。
Applied_Tariff_Percent	float	%	对应年份适用于半导体（HS8541/8542）的有效关税税率。
Export_Control_Intensity	int	0–5	出口管制强度等级：0（无管制）到 5（最强，比如 2023 GPU 全面封锁）。
Notes	string	文本	补充信息，如适用范围、政策意图等。
📌 4. 表：Chip_Tier_HSCode_Mapping.csv

芯片种类与 HS Code 对照表。用于构建高/中/低端芯片的分组虚拟变量。

列名称	类型	单位	说明
Tier	string	类别	芯片等级：High / Mid / Low。
HS_Codes	string	HS Code 列表	采用分号分隔的多个 HS 子目代码。
Description	string	文本	芯片类型描述，如“先进逻辑、GPU”等。
